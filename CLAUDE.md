# CLAUDE.md

Project conventions for agents live in **[AGENTS.md](./AGENTS.md)** — read it first.

Most important, because they fail silently:

- **Contract addresses have ONE home: `@workspace/contracts`** (`packages/contracts/src/index.ts`). Never hard-code an address or add a `*_LAUNCH_FACTORY` env var — the web app and indexer both import the package so they can't point at different factories.
- **ABIs are generated by `node packages/contracts/scripts/gen-abis.mjs`** (pulls from the private `launchpad-contracts-v2` repo via `gh`), never hand-edited.
- **The indexer's event ABIs must byte-match the deployed contracts** or it indexes zero launches with no error. The single and multi factories emit same-named events with different shapes.
- **There is no graduation in v2.** The launch position is the curve and never migrates; any "graduated" copy or progress bar is a leftover.

See AGENTS.md § "Contract addresses, ABIs, and the indexer" for the full checklist.
